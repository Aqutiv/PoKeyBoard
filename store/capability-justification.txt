PoKeyBoard is a PWA packaged with Microsoft's PWABuilder. runFullTrust enables Microsoft Edge to host the modern app and PWABuilder's classic launcher to open the same web app on older Windows versions. URL: https://aqutiv.github.io/PoKeyBoard/. It installs no custom native service, requires no administrator rights at runtime, and performs no background monitoring. Optional MIDI/Bluetooth access uses browser permission prompts; imports and exports are user initiated.
